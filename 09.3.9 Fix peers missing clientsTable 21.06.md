# 09.3.9 Fix peers missing clientsTable 21.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Commit: fd66b0a fix: show peers missing clients table
Version: v1.2.35
Симптом
Инстанс выбран правильно, но старые клиенты не появляются в таблице Пользователи.
Причина
UI строил список только из clientsTable. У старых/созданных приложением клиентов peer может быть в awg0.conf, а запись clientsTable отсутствовать или иметь другой формат.
Исправлено
GET /api/clients теперь возвращает union clientsTable + Peer из awg0.conf.
Peer-only строки показываются как Peer xxxx… и помечаются missingClientTable.
Rename/date/disable/delete умеют работать с peer-only строками.
Для экспорта .conf всё равно нужен импорт клиентского .conf, потому приватный ключ клиента сервер не знает.
Команда
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
Потом Ctrl+F5.
