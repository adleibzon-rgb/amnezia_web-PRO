# 09.3.8 Fix clients selected profile 21.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Commit: cb5fca3 fix: load clients for selected profile
Version: v1.2.34
Симптом
Переключатель Инстанс показывает правильный контейнер, но таблица Пользователи показывает клиентов от другого/старого инстанса.
Причина
Создание/экспорт уже передавали profileId явно, но /api/clients и операции таблицы опирались на cookie выбранного профиля. Cookie мог не примениться/устареть, поэтому список клиентов приходил не от выбранного инстанса.
Исправлено
GET /api/clients принимает явный profileId.
disable/enable/rename/delete/disconnect-date используют runtimeFromExportRequest и body.profileId.
Frontend передаёт profileId во все запросы таблицы клиентов.
Docs обновлены.

curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
