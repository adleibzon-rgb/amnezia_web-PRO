# 09.3.6 Fix duplicate AWG instances 21.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Project: amnezia_web-PRO
Commit: 8c67d7d fix: dedupe duplicate awg instances
Version: v1.2.32
Причина
После переустановки один и тот же AWG контейнер мог попасть в список дважды: из AWG_PROFILES и из saved managed instances. Старый dedup был только по id, поэтому при разных id веб показывал две одинаковые карточки.
Исправлено
Dedup профилей по container + confPath + iface + clientsPath.
/api/instances дополнительно дедупит runtime target после auto-resolve контейнера.
load/save managed profiles чистит дубли из instances.json.
Docs обновлены: раздел Инстансы задублировались.
Команда для пользователя
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
После установки: Ctrl+F5 в браузере.
