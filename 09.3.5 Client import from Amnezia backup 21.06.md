Что добавлено
В панели появился блок Импорт клиента.
Можно вставить готовый клиентский .conf или JSON backup Amnezia, если внутри есть текстовый .conf.
Если peer уже есть в awg0.conf, дубль не создаётся: восстанавливается/обновляется строка clientsTable.
Если peer отсутствует, он добавляется в текущий выбранный Инстанс.
Исходный .conf сохраняется в userData.last_config, чтобы дальше работали экспорт и управление из веба.
Добавлена защита: импортируемый .conf должен относиться к текущему серверу/инстансу по PublicKey сервера.
Команда переустановки для пользователя
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
Проверено
node --check server.js
node --check public/app.js
bash -n для всех scripts/*.sh
npm audit --audit-level=moderate: 0 vulnerabilities
git diff --check
Что сказать пользователю
Обновите панель командой выше, зайдите в веб, выберите нужный Инстанс и откройте блок Импорт клиента. Вставьте экспортированный клиентский .conf из приложения Amnezia или backup, где внутри есть этот .conf. После импорта клиент появится в таблице, а старые peer-дубли создаваться не будут.
