# 09.3.7 Fix AWG instance labels 21.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Commit: a9a67af fix: show distinct awg instance labels
Version: v1.2.33
Причина
У пользователя реально два контейнера: amnezia-awg2 и amnezia-awg. Порты и число клиентов разные, значит это не дубль. Но UI рисовал title по variant, поэтому обе карточки выглядели как AmneziaWG 2.0.
Исправлено
Карточка инстанса показывает profile label, а не только variant title.
Backend лучше определяет variant по profile/container/label до чтения конфига.
Docs уточнены: два разных контейнера с разными портами — нормальные два инстанса.
