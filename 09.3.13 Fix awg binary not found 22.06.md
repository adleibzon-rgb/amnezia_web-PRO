# 09.3.13 Fix awg binary not found 22.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Commit: 8e5d51a fix: auto-detect wg binary in containers
Version: v1.2.39
Symptom
При добавлении/подтягивании старых .conf ошибка: sh: awg: not found. В amneziawg контейнере awg binary отсутствует.
Fix
Runtime auto-detects binary inside container: preferred wgBinary, then wg for wg0.conf, then awg, then wg.
show/pubkey/genkey/syncconf use resolved binary, not hardcoded profile.wgBinary.
source-report and /api/clients expose resolved wgBinary.
Command
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
Then Ctrl+F5 → Instance → Users → Pull from awg0.conf.
