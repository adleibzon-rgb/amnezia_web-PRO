# 09.3.12 Fix Amnezia source auto-discovery 22.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Commit: b360095 fix: auto-discover amnezia client sources
Version: v1.2.38
Root cause
Amnezia installs can keep old clients in /opt/amnezia/awg/wg0.conf, while profile pointed to /opt/amnezia/awg/awg0.conf. clientsTable can also live in /opt/amnezia/wireguard/clientsTable or have non-array format.
Fix
Runtime now scans config candidates: awg0.conf, wg0.conf, wireguard/wg0.conf.
Chooses config with max [Peer] count.
Runtime scans clientsTable candidates: awg/clientsTable and wireguard/clientsTable.
Chooses clientsTable with max parsed client count.
iface is inferred from selected config filename.
source-report shows resolved confPath/clientsPath/iface.
Command
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
Then Ctrl+F5 → select Instance → Users → Pull from awg0.conf.
Source
Amnezia issue #1615 mentions manual flow with /opt/amnezia/awg/wg0.conf and clientsTable; issue #2238 confirms clientsTable field variance.
