# 09.3.10 Sync app-created Amnezia users 21.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Задача
Клиенты уже были созданы в приложении Amnezia. Их нужно подтянуть в веб-панель, а не создавать заново.
Решение
Добавлена кнопка Пользователи → Подтянуть из awg0.conf.
POST /api/clients/sync-peers берёт активные [Peer] текущего инстанса и создаёт недостающие строки clientsTable.
VPN-конфиг не пересоздаётся, контейнеры клиентов не трогаются.
Имена создаются как Клиент IP или Peer KEY, потом можно переименовать.
Экспорт .conf появится после импорта клиентского .conf, потому приватный ключ клиента есть только в приложении.
Команда
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
Потом Ctrl+F5 → выбрать Инстанс → Пользователи → Подтянуть из awg0.conf.
