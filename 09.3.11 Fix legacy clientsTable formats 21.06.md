# 09.3.11 Fix legacy clientsTable formats 21.06

_Старая заметка из Notes (июнь 2026), перенесена 23.10.2026. Оригинал: Архив/Старые заметки Notes 20261023._

Commit: 4e6ab2d fix: parse legacy clients table formats
Version: v1.2.37
Причина
Старые клиенты могли не подтягиваться, если clientsTable не был массивом [{clientId,userData}], а имел object/map/nested формат другой версии Amnezia.
Исправлено
parseClientsTable поддерживает array, object map, nested clients/users/rows/items/data/clientList/clientsTable.
clientRowId понимает clientId/id/publicKey/public_key/key/client_id и вложенные userData поля.
Добавлен GET /api/clients/source-report для диагностики источников без полных ключей.
Команда
curl -fsSL "https://raw.githubusercontent.com/andrey271192/amnezia_web-PRO/main/scripts/install.sh?nocache=$(date +%s)" | sudo env SKIP_LANDING=1 bash
Потом Ctrl+F5 → выбрать Инстанс → Пользователи → Подтянуть из awg0.conf.
Если всё равно пусто
Открыть в браузере после логина: /api/clients/source-report?profileId=awg и /api/clients/source-report?profileId=awg2
